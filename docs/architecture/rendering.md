# Rendering Architecture

## Responsibilities
The rendering layer (frontend) is strictly limited to **visualization**. It is explicitly forbidden from:
- Inventing electrical connections
- Generating unverified engineering state
- Executing simulations
- Calling AI models

The canonical engineering truth always resides in the `DesignProject` JSON generated by the backend orchestrator and validator.

## Data Flow
`DesignProject` (JSON) -> `SceneBuilder` (TypeScript) -> `SceneGraph` -> `React Three Fiber` / `Canvas 2D`

## SceneGraph
The `SceneGraph` is an intermediate representation built deterministically from the `DesignProject`.
- **Nodes**: Contain positional transforms, rotation, and primitive visual type keys, along with local anchor maps for pins.
- **Wires**: Contain an array of 3D points (a polyline path) mapped out from the origin and destination anchors.
- **Labels**: Expose instance IDs for both the 2D schematic and 3D floating text.

## Deterministic Layout
Because the AI is not permitted to hallucinate coordinates during Phase 4, the `SceneBuilder` currently employs a simple fallback layout algorithm if `layout` hints are omitted from the IR (linear alignment along the X-axis). Given the exact same `DesignProject` JSON input, the math produces the exact same `SceneGraph`, guaranteeing stability.

## Asset Abstraction
Visual rendering relies on a string-mapped abstraction (`visual_type`).
Presently, types like `board`, `sensor`, `led`, and `resistor` map to procedural Three.js primitives (boxes, cylinders) to minimize bloat. In future phases, these mappings will point directly to GLB/glTF asset bundles provided by the backend registry.

## 2D Renderer
Implemented via a raw HTML5 `<canvas>`. It maps the 3D X and Z coordinates into 2D X and Y pixel space, rendering simple stroked rectangles and connection lines to ensure the topology is legible at a glance.

## 3D Renderer
Implemented via `@react-three/fiber` and `@react-three/drei`. It renders the procedural geometry over a placeholder breadboard base with OrbitControls for panning, zooming, and rotation. Components support raycasted click events for cross-referencing instance metadata in the sidebar.
